# Красимир Димитров — кларинетист

Личен сайт на кларинетиста Красимир Димитров. По подразбиране е на български, с превключване към английски.

## Локално

Отвори `index.html` в браузър или стартирай прост сървър от тази папка:

```bash
python -m http.server 8080
```

После: http://localhost:8080

## GitHub Pages

След качване в GitHub: **Settings → Pages → Deploy from a branch → `main` / root**.
Сайтът ще е на `https://lukezester-ai.github.io/krassimir-dimitrov/`.

Ако Pages все още не е активен: **Settings → Pages → Source: GitHub Actions**.
